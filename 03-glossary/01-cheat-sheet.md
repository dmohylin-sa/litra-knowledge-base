# Cheat sheet - one page before you walk in

> **In short:** if you read only one page, read this one.

## Litra in five facts

1. Norwegian transport group, **founded 1917**. Energy division hauls **fuel, gas, bulk liquids and chemicals**.
2. Active in **Norway, Sweden, Finland, Denmark**. Roughly **400-500 trucks**, **800-900 people** (confirm).
3. **20+ isolated systems, 30+ manual handoffs.** Paper waybills, email orders, Excel billing.
4. **UBW (Unit4)** stays as the ERP. Telematics stays. Planning tools, driver apps and Excel billing can go.
5. They judge on four pillars: **functional core, ML and ESG, web plus tablet, ROI.**

## The flow in one line

**Order → validate → ML proposes plan → planner confirms → driver loads (e-CMR) → live tracking → POD → reconcile → within tolerance? → price → invoice → UBW.**

## 25 words you must know

| Word | Means |
|---|---|
| **Haulier** | The company that moves the goods: Litra |
| **Shipper / consignee** | Who sends / who receives |
| **Fleet Planner** | Turns orders into trips; also called dispatcher |
| **Trip** | One truck, one driver, one or more stops in a row |
| **Compartment** | A section of the tank; one product each |
| **Tractor + semi-trailer** | Truck head that pulls a tank trailer; licence CE |
| **Rigid truck** | Truck and tank in one; fits small sites |
| **Terminal** | Depot where the truck loads fuel or gas |
| **Standard litres at 15 °C** | Volume corrected for temperature; what fuel is traded in |
| **ADR** | European rules for dangerous goods by road |
| **UN number** | Four-digit product code: diesel 1202, petrol 1203, LPG 1965 |
| **Tunnel code** | Which road tunnels a dangerous load may not use |
| **EU 561** | Driving and rest time law; 9 h a day, 10 h twice a week |
| **Tachograph** | Device that records a driver's driving and rest |
| **e-CMR** | Electronic waybill, legally equal to paper |
| **POD** | Proof of delivery: signature or photo |
| **Telematics** | Truck reports position, km and events automatically |
| **rFMS** | Standard interface to read truck data across brands |
| **Geofence** | Virtual circle around a site; proves arrival and waiting |
| **EDI (IFTMIN)** | Machine-to-machine order message from a customer |
| **Reconciliation** | Comparing planned vs actual before billing |
| **Tolerance** | How much actual may differ from plan and still auto-bill |
| **Rate card** | Price list in a contract: per m³ by zone, per tonne, km + hour |
| **Credit note** | Document that cancels a posted invoice, fully or partly |
| **UBW** | Litra's ERP (Unit4); records and sends invoices |

## Key numbers

| Topic | Number |
|---|---|
| Daily driving limit | **9 h**, **10 h** twice a week |
| Break | **45 min** after **4.5 h** driving |
| Weekly / two-week driving | **56 h** / **90 h** |
| ADR driver certificate | Valid **5 years** |
| Diesel volume change | About **0.08% per °C** |
| Default tolerances | km **±5%**, time **±10%**, quantity **±0.5%**, waiting **±10 min** |
| eFTI (EU electronic freight info) | Authorities must accept from **9 July 2027** |
| Build window under discussion | **April to December 2027** |
| ML history wanted | **12+ months** of trips and orders |

## Three messages to land

1. **One order, zero re-keying.** Data is entered once and reused to the invoice.
2. **The machine proposes, the planner decides.** ML within hard rules, with reasons.
3. **Billing from facts.** Every invoice line traces back to telematics, POD or contract; only exceptions reach a person.
